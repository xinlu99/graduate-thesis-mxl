\section{研究背景与意义}
% ============================================================

天地一体化信息网络是支撑全球通信、遥感感知、任务协同与智能服务的重要基础设施。随着低轨卫星星座持续部署、星间链路逐步完善以及星载计算平台能力不断提升，卫星节点的功能定位正在由单一的数据中继载体演进为具备在轨处理、任务协同和资源调度能力的分布式协同计算平台\cite{ref1,Wang2024NTN,Hu2023SECSurvey}。这种演进不仅提升了网络服务能力，也对网络运行模式、任务组织方式和资源管理机制提出了新的要求。

在卫星终端试验任务场景中，试验数据具有来源分散、链路受限、时效要求高和过程需可追溯等特点。特别是在灾害应急通信、对地观测快速处理、区域目标识别、空间态势感知和跨区域任务协同等场景中，系统不仅需要完成数据采集与远程传输，还需要在有限可见窗口和受限链路条件下实现任务接入、资源协调、计算处理与结果反馈的快速闭环。若仍依赖传统"星上初步处理—地面集中分析"的工作模式，则容易受到星地链路时延、可见窗口和地面中心计算瓶颈的制约，难以满足高时敏业务对快速响应和在轨闭环处理的实际需求\cite{Hu2023SECSurvey,Guo2024E2E}。

在此背景下，将计算能力由地面向星上前移，并在多颗卫星之间实现资源共享与协同处理，已成为提升天基网络智能服务能力的重要发展方向。所谓协同计算卸载，是指当任务接入卫星本地资源不足或本地执行代价过高时，通过星间链路将任务迁移至其他具备可用资源的协同节点执行，从而在更大范围内实现算力共享与负载分担\cite{ref1,Guo2024E2E}。图~\ref{fig:ch1_scenario}给出了天基网络协同计算卸载的典型应用场景。在该场景中，地面突发任务首先通过上行链路接入当前服务卫星；当该卫星本地资源不足或任务积压严重时，可将部分任务经由星间链路卸载至资源相对空闲的卫星节点执行；同时，卫星节点利用区块链共识机制以异步、非实时的方式共享候选节点资源信息和任务生命周期事件，支撑可信状态共享、协同决策和结果反馈。

然而，天基网络中的协同计算卸载并不是传统意义上的简单任务迁移问题。与地面云计算和边缘计算环境相比，天基网络节点资源更加受限，链路拓扑变化更加频繁，运行环境也更加动态复杂。卫星高速运动使得网络拓扑、链路质量和可见窗口持续变化，不同卫星节点在剩余算力、存储资源、链路状态和能量水平等方面存在显著异质性；多颗卫星在同一时刻既可能是任务发起方，也可能是资源提供方，节点之间存在资源竞争与收益耦合。因此，天基协同计算卸载不仅要解决"任务是否卸载、卸载到哪里"的问题，还需要进一步解决状态是否可信、资源如何协同、并发执行代价如何刻画等问题。

结合上述背景，本文研究主要面临以下三个关键挑战：

（1）高动态环境下的可信状态共享问题。协同卸载依赖节点算力占用、剩余能量、链路连通性、队列长度和任务执行状态等信息。然而，天基网络中的链路连接具有间歇性和时变性，频繁广播全局状态不仅会增加通信负担，还可能因传播时延和局部信息缺失造成多节点认知不一致。对于缺乏长期稳定中心控制节点的天基环境而言，若共享状态存在篡改、滞后或失真，后续资源分配和任务卸载决策将缺乏可靠依据。因此，如何在高动态拓扑下构建可追溯、低冲突、可验证的状态共享机制，是本文面临的首要挑战。

（2）多节点资源竞争下的系统层协同问题。多颗卫星在同一时刻可能同时发起卸载请求，资源充足或链路条件较好的卫星节点容易成为竞争热点。若各节点仅依据局部收益进行贪婪选择，容易导致负载集中、策略震荡和系统吞吐下降；同时，节点既是任务发起方又是资源提供方的双重身份还会引发自利行为，使得局部最优与全局协同收益之间产生矛盾。因此，如何在去中心化、信息不完全和资源竞争条件下，建立兼顾任务完成质量、负载公平性和长期协作收益的系统层协同决策机制，是本文面临的第二个关键挑战。

（3）异步链上信息与并发开销耦合下的任务层实时卸载问题。系统层协同能够为任务卸载提供候选节点集合、公共状态摘要和信誉约束，但区块链共识机制本质上提供的是异步、非实时的全局信息共享，链上记录的节点状态相对于真实运行状态存在固有时滞。当新任务到达卫星终端时，终端需在较短时间内结合本地状态、链路条件，以及链上记录的候选节点资源信息和正在执行任务信息作出具体卸载动作。同时，新任务一旦卸载至目标节点，便会与该节点上正在执行的任务争用计算资源，由此引入并发开销——其同时包括新任务自身的计算时延以及对存量任务剩余执行时延的延长，受任务异构性和节点动态负载共同影响，传统"传输时延+计算时延"的线性建模难以准确刻画。因此，如何在链上信息存在异步时滞、节点运行数据难以集中共享和多任务并发开销难以解析建模的条件下，实现具备并发开销感知能力的任务层实时卸载决策，是本文面临的第三个关键挑战。

针对上述问题，本文围绕"统一建模—系统层协同—任务层卸载"的研究主线展开。首先构建面向天基网络可信协同计算卸载的统一建模框架，并将总体问题分解为系统层协同资源分配和任务层并发开销感知卸载两个子问题；随后分别研究基于区块链与多智能体强化学习的系统层协同资源分配方法，以及基于聚类联邦学习与DQN的任务层实时卸载方法。

综上所述，本文研究面向灾害应急通信中的快速响应闭环、对地观测数据的在轨实时处理以及跨区域协同任务的可信调度等典型天基应用场景，有助于完善高动态、资源受限、去中心化网络环境下的协同计算卸载建模方法，为可信状态共享、多节点资源博弈和并发感知卸载决策提供新的研究思路；同时，可为区块链可信记录、任务卸载决策和模型治理的一体化支撑机制提供参考，推动天基边缘计算体系的工程化建设，具有一定的理论意义与应用价值。

\section{国内外研究现状}
% ============================================================

围绕天基网络协同计算卸载问题，国内外研究已从体系架构、任务卸载、智能调度、去中心化协同和隐私保护建模等多个角度展开探索。总体来看，相关研究正沿两个方向并行推进：一方面，卫星边缘计算与星间协同处理不断走向实用化，任务卸载与资源调度问题逐步由静态建模转向动态学习；另一方面，随着网络规模扩张和节点自治能力增强，可信共享、分布式共识、联邦学习以及区块链辅助机制日益成为研究重点。基于此，本节从天基网络计算卸载与轨道边缘计算、区块链辅助可信状态共享与协同调度、智能优化驱动的多节点资源分配与任务卸载三个方面进行梳理，并据此明确本文的研究定位。

\subsection{天基网络计算卸载与轨道边缘计算研究现状}

随着低轨卫星星座的快速发展，卫星边缘计算已成为天基网络研究中的热点方向。已有研究普遍认为，未来卫星网络不应仅承担透明转发功能，而应具备在轨预处理、局部协同分析和边缘服务承载能力，以缓解地面中心压力并提升实时响应能力\cite{Hu2023SECSurvey,Yin2025OECSurvey}。围绕这一目标，学界先后提出星地协同、星间协同和天地融合等多种计算架构，试图根据任务复杂度、时延要求和资源约束，在终端、卫星与地面之间灵活划分处理位置。

在具体卸载方法方面，早期研究多采用解析优化、启发式搜索或博弈论方法，对时延、能耗和资源利用率进行联合建模。这类方法在问题规模较小且假设条件较强时具有较好的可解释性，但当网络拓扑频繁变化、链路状态动态波动或任务到达具有突发性时，其模型有效性往往难以长期保持。例如，Gao等针对LEO星座网络中的分布式动态卸载问题，基于博弈论建立了联合计算卸载与功率分配模型，在分布式环境下优化了资源利用效率，但该方法的求解过程依赖较强的信道静态假设\cite{ref19}。

自2024年以来，相关研究开始更加重视卸载问题中的时变信道、队列状态和动态负载因素。Jia等提出面向卫星边缘计算的深度多智能体强化学习方法MATORA，将任务卸载与资源分配拆分求解，在动态负载条件下提高了时延优化能力\cite{ref22}。Li等针对LEO卫星边缘计算网络研究了基于多智能体强化学习的联合卸载与资源分配问题，通过分布式学习处理高动态环境中的能耗与时延折中\cite{Li2024MARLComCom}。Shuai等讨论了基于Q-learning的卫星边缘计算卸载策略，进一步验证了强化学习方法在动态卫星场景中的适应性\cite{Shuai2024Qlearning}。与此同时，Tang等研究了基于星间链路的星地一体化网络任务卸载与资源分配问题，提出混合云与卫星多层多接入边缘计算架构，通过联合优化节点选择、卸载比率和算力分配实现了网络资源的动态管理\cite{ref20}。

进入2025年以后，研究重点进一步从"是否卸载"扩展到"如何在多目标条件下稳定卸载"。Wang等提出面向卫星边缘计算的多目标强化学习卸载方法，将时延、资源利用率和负载均衡纳入统一优化目标，改善了复杂任务场景下的综合性能\cite{LMCECN2025}。Zhong等则着重分析了异构任务需求、资源竞争和联合分配之间的耦合关系，指出卸载研究正在由单一指标优化转向服务质量约束和多资源联合编排\cite{Zhong2025HeterogeneousTVT}。在此基础上，Xiu等提出MARATD3算法，将循环神经网络与多头注意力机制引入多智能体深度确定性策略梯度框架，在部分可观测条件下实现了跨时隙的动态卸载与资源分配联合优化，为高动态卫星环境中的序贯决策问题提供了新的建模范式\cite{Xiu2025MARATD3}。

这些研究表明，卫星边缘计算与任务卸载已由概念验证阶段逐步迈向细粒度建模与智能优化阶段。2024—2026年天基计算卸载与智能调度领域的代表性研究如表~\ref{tab:ch1_offloading_survey}所示。

尽管相关研究已取得显著进展，但仍存在两方面关键局限。其一，多数工作默认系统能够获得较准确的全局或准全局状态，未能有效刻画高动态拓扑下的状态不一致、信息失真和分布式认知偏差；其二，大量模型仍将任务代价简化为传输时间与纯计算时间的线性叠加，对多任务并发带来的内部竞争和执行扰动刻画不足，导致实际卸载决策中的代价估计存在系统性偏差。本文正是针对上述两个维度的不足，在"可信共享"和"并发感知"层面推进天基计算卸载研究。

\subsection{区块链辅助的可信状态共享与协同调度研究现状}

随着天基网络从封闭体系向开放协同体系演进，可信共享与去中心化协同问题日益突出。传统中心控制模式虽便于统一管理，但在大规模低轨星座和多主体参与环境下，容易面临单点失效、扩展性不足以及状态采集开销过高等问题。为此，近年来研究开始尝试引入区块链、分布式共识和自治网络协议，为天基网络构建新型协同机制。

2024年以来，该方向的代表性工作明显增多。例如，Elmahallawy等围绕多厂商低轨卫星网络提出面向空间智能的去中心化信任框架，强调通过区块链与联邦学习协同提升跨主体协作的鲁棒性与可用性\cite{Elmahallawy2025}。Zhai等提出面向低轨卫星网络的联邦学习框架 FedLEO，通过卸载辅助与去中心化训练机制提升分布式学习效率\cite{ref30}。与此同时，面向空天地一体化网络的区块链安全通信研究也在增加，Du等提出 StarCross 可编辑区块链跨分片数据共享框架，表明通过链结构与交易机制创新可缓解卫星网络中的区块链性能瓶颈\cite{ref28}。

在区块链与计算卸载的结合方面，2025年的一项重要进展值得关注。相关研究提出了区块链辅助的数字孪生卸载机制，在空天地异构网络中构建了SAG数字孪生集成区块链模型，利用区块链保障数据安全与隐私的同时，通过数字孪生实现网络状态的实时映射与优化，并给出了高效的任务卸载与资源分配联合算法\cite{ref27}。该工作将区块链由"外部安全模块"推进到"与卸载决策紧密耦合的状态底座"，与本文的核心理念高度契合。此外，面向卫星物联网的StarCross框架提出了可编辑区块链跨分片交易方案，说明通过架构创新可以有效缓解卫星网络中区块链的性能瓶颈\cite{ref28}。

进入2025—2026年，研究重点进一步由"能否去中心化"转向"如何在高动态卫星网络中实现更稳健的共识与控制"。相关研究针对高覆盖联盟链场景提出了网络拓扑感知的容错共识机制，表明传统地面分布式机制难以直接迁移到卫星网络环境，必须围绕链路质量、节点能力与覆盖约束进行针对性重构\cite{NetTopoBFT2025}。这一趋势表明，去中心化卫星网络研究已由宏观愿景逐步走向面向工程实现的机制设计阶段。

尽管如此，当前研究主要回答了"为什么需要去中心化"和"如何构建分布式信任机制"，但对这些机制如何有效服务于具体的计算卸载、资源协调和任务调度，仍缺少系统性设计。已有工作中，区块链与卸载决策的耦合通常停留在"数据安全保障"层面，尚未形成覆盖状态记录、节点选择、执行反馈和信誉更新的完整闭环。本文将区块链由"外部安全模块"转化为"可信状态底座"，使其同时服务于系统层协同资源分配和任务层实时卸载，在这一耦合维度上推进现有研究。

\subsection{智能优化驱动的多节点资源分配与任务卸载研究现状}

天基网络环境具有高动态、强耦合和多主体并存等特征，面向动态环境的智能调度已成为近年来相关研究的核心方向。深度强化学习之所以被广泛引入，在于其能够在缺乏精确解析模型的条件下，通过与环境持续交互形成状态到动作的映射关系，从而有效处理链路波动、任务到达随机性和资源时变性等问题\cite{Tang2022DRL,Shuai2024Qlearning}。

在单智能体强化学习阶段，研究通常聚焦单节点视角下的卸载动作、功率控制或链路选择，通过DQN、DDQN、D3QN等方法提升策略对复杂状态的适应能力。此类方法在小规模、中心化或弱耦合场景中效果较好，但当多个卫星节点同时参与决策时，其隐含的"环境平稳"假设不再成立。对任一节点而言，其他节点的动作会持续改变其观测环境和收益分布，导致单智能体方法面临显著的环境非平稳性问题。

基于这一认识，多智能体强化学习在天基计算调度中日益受到重视。2024年以后，多项研究明确将多颗卫星建模为多智能体系统，通过集中训练分散执行（CTDE）或共享奖励等机制处理节点间的策略耦合关系\cite{Li2024MARLComCom,Xiu2025MARATD3,ref23}。在CTDE范式的具体实现方面，Wu等提出了面向LEO卫星网络的多智能体深度强化学习卸载与路由联合优化方法，将计算和路由需求同时纳入多智能体建模框架，在动态负载和拓扑变化条件下展现了分布式决策的灵活性\cite{ref23}。Qin等则从可持续计算角度出发，利用MARL解决星地一体化网络中的计算卸载问题，强调全局奖励设计在多智能体收敛中的关键作用\cite{Qin2023MARL}。

在隐私保护协同建模方面，联邦学习逐渐成为支撑天基网络分布式智能建模的重要方案。与传统集中式学习相比，联邦学习允许各节点在本地完成训练，仅交换模型参数或梯度，在"数据不出域"的前提下实现跨节点协同优化\cite{Bonawitz2019,Matthiesen2024FLSatellites}。在卫星及星地融合场景中，联邦学习研究近两年呈现出两条清晰路径：一是围绕具体业务构建面向天基环境的协同学习框架，二是围绕高动态、异构和隐私约束条件改进联邦学习机制本身。已有研究表明，联邦学习不仅能够降低原始数据汇聚压力，还能在异构节点条件下提升模型泛化能力。

总体而言，智能优化方法为天基网络多节点资源分配与任务卸载提供了重要工具，但现有研究仍存在两类不足：一是系统层多智能体协同通常将可信状态视为已知前提，未能回答"卫星节点如何在去中心化环境下获得可信的他方状态"这一基础问题，使得自利行为和局部信息不对称难以从根本上得到约束；二是任务层深度强化学习多将环境代价直接作为即时反馈，对并发开销、状态时滞和联邦预测之间的闭环关系刻画不足，导致实际代价与模型输入之间存在结构性偏差。本文在统一问题模型下，以区块链可信状态共享回答第一类问题，以聚类联邦学习与并发开销建模回答第二类问题，通过分层耦合实现两个层面的协同。

\section{本文主要研究内容}
% ============================================================

本文旨在面向卫星终端试验任务和天基协同计算场景，研究高动态、资源受限和去中心化环境下的可信协同计算卸载方法。针对天基网络中节点状态难以可信共享、多节点资源竞争关系复杂以及并发任务执行代价难以准确刻画等问题，本文围绕统一建模与问题分解、系统层协同资源分配以及任务层并发感知卸载三个层面开展研究，主要研究内容如下：

（2）基于区块链与多智能体强化学习的系统层协同资源分配方法。针对去中心化天基网络中节点自利、状态不完全和资源竞争导致的负载失衡问题，本文将多个异构卫星节点之间的长期资源协同建模为多智能体马尔可夫博弈，利用联盟链维护节点负载、链路状态、信誉评分和历史行为等公共摘要，结合集中训练—分散执行机制和融合任务完成质量、公平性与信誉激励的混合奖励函数，引导异构节点在自治条件下实现多节点稳定的协同资源分配。

（3）基于聚类联邦学习与DQN的并发感知任务层计算卸载方法。针对区块链共识机制引入的异步时滞、节点数据隐私受限和多任务并发开销难以准确建模等问题，本文提出FL-DQN集成决策框架：建立面向计算资源竞争的并发开销模型，将新任务计算时延和存量任务剩余时延延长统一纳入代价函数；按节点并发任务数进行分簇，采用聚类联邦学习训练并发开销预测模型；将预测结果、本地状态和链上候选节点信息共同输入深度Q网络，实现具备并发开销前瞻能力的任务层实时卸载决策。

第\ref{chap:ch5_task_offloading}章为基于聚类联邦学习与DQN的并发感知任务层计算卸载方法。本章面向第\ref{chap:ch3_unified_model}章提出的任务层并发感知卸载子问题，在区块链账本提供的候选节点信息与系统层输出的信誉约束基础上，研究链上信息存在异步时滞、节点数据隐私受限和多任务并发开销耦合条件下的实时卸载决策机制，验证所提FL-DQN框架在预测精度、端到端时延、SLA完成率和链上信息时滞鲁棒性等方面的有效性。

最后一章为总结与展望。本章总结全文研究工作和主要结论，分析当前研究仍存在的不足，并对未来可进一步开展的研究方向进行展望。
