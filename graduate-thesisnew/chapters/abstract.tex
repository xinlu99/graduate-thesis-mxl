\begin{abstract}
  随着天地一体化信息网络、低轨卫星星座和在轨智能处理技术的发展，天基网络正由传统数据传输网络向集通信、计算、存储与智能处理于一体的分布式协同计算网络演进。卫星终端试验任务数据具有来源分散、链路受限、时效性强和过程需可信记录等特点，传统星地集中处理模式易受可见窗口、回传带宽和传输时延限制，单星本地处理又受算力、能量、存储和星间链路条件约束，难以持续支撑高并发、高动态任务的快速闭环处理。因此，本文拟解决的核心问题是：在高动态、资源受限和去中心化的天基网络环境中，如何在节点状态难以实时一致、资源竞争关系复杂、任务执行过程存在并发开销的条件下，实现可信、高效的多星协同计算卸载。

  针对上述问题，本文围绕天基网络可信协同计算卸载需求，融合区块链、多智能体强化学习、联邦学习和深度强化学习等技术，形成“统一建模—系统层协同—任务层卸载决策”的研究主线。本文首先构建面向天基网络可信协同计算卸载的统一建模框架，明确节点、任务、链路、资源、区块链账本可信状态与执行反馈之间的关系；随后在统一模型下分别研究系统层协同资源分配方法和任务层并发感知计算卸载方法。本文主要研究内容如下：

  （1）构建面向天基网络可信协同计算卸载的统一建模框架。针对天基网络节点异构、链路时变、任务随机到达和状态共享可信性不足等问题，本文建立包含卫星终端、卫星边缘节点、地面控制中心和区块链账本的协同计算模型，分别刻画节点资源、任务属性、链路传输、计算时延、能耗开销、节点信誉和任务生命周期记录过程。在此基础上，将总体协同计算卸载问题分解为系统层协同资源分配问题和任务层并发开销感知卸载问题，为后续方法设计提供统一符号体系、状态接口和优化目标。

  （2）提出基于区块链与多智能体强化学习的系统层协同资源分配方法。针对去中心化天基环境中节点自利、信息不完全和资源竞争导致的负载失衡问题，本文将系统层资源分配建模为多智能体马尔可夫博弈，构建区块链增强的集中训练—分散执行协同决策框架。该方法利用联盟链维护节点负载、链路状态、信誉评分和历史行为等公共摘要，并设计融合任务完成质量、系统公平性与信誉激励的混合奖励机制，引导异构卫星节点在自治条件下实现稳定协同。结果表明，所提方法能够有效提升任务完成率和负载均衡水平，在典型负载场景下任务完成率达到 92.3\%，Jain 公平指数达到 0.918；在高负载条件下仍能保持较高任务完成率，并有效降低平均任务时延。

  （3）提出基于聚类联邦学习与DQN的并发感知任务层计算卸载方法。针对多任务并发条件下 CPU 时间片、缓存、内存带宽和 I/O 队列竞争引发的隐性执行代价，本文建立任务级并发开销模型，将新任务自身计算时延以及新任务加入后对存量任务造成的剩余时延增加统一纳入代价刻画，并构建“聚类式联邦学习预测 + DQN 卸载决策”的闭环机制。该方法在不上传原始任务日志的前提下，通过聚类式联邦学习训练并发开销预测模型，并将预测结果、本地状态和区块链账本维护的可信公共摘要共同输入深度 Q 网络，使卫星终端能够在状态时滞和节点数据异构条件下完成具备并发开销前瞻能力的卸载决策。结果表明，在高并发场景下，所提 FL-DQN 方法的平均任务时延为 256 ms，SLA 完成率达到 84.7\%，优于 DQN-only、FL-only 和启发式卸载策略。

  综上，本文围绕高动态天基网络中的可信协同计算卸载问题，形成了“统一建模—系统层协同—任务层卸载决策”的研究体系，可为资源受限条件下天基网络任务处理效率、自治协同能力和可信运行水平提升提供理论依据与方法支撑。
\end{abstract}


\begin{abstractEn}
  With the development of space-ground integrated information networks, low Earth orbit satellite constellations, and on-orbit intelligent processing technologies, space-based networks are evolving from traditional data transmission networks into distributed collaborative computing networks integrating communication, computation, storage, and intelligent processing. Satellite terminal test task data are characterized by distributed sources, constrained links, strict timeliness requirements, and the need for trustworthy process recording. Traditional space-ground centralized processing is limited by visibility windows, feeder link bandwidth, and transmission latency, while single-satellite local processing is constrained by onboard computing capability, energy, storage, and inter-satellite link conditions. Therefore, this thesis focuses on the following core problem: how to achieve trustworthy and efficient multi-satellite collaborative computation offloading in highly dynamic, resource-constrained, and decentralized space-based networks where node states are difficult to keep consistent in real time, resource competition is complex, and concurrent execution introduces concurrency overhead.

  To address this problem, this thesis studies trusted collaborative computation offloading for space-based networks by integrating blockchain, multi-agent reinforcement learning, federated learning, and deep reinforcement learning. The research follows a unified line of “unified modeling--system-layer collaboration--task-layer offloading decision-making”. A unified modeling framework is first established to describe nodes, tasks, links, resources, blockchain-based trusted states, and execution feedback. Based on this framework, the system-layer collaborative resource allocation problem and the task-layer concurrency-aware computation offloading problem are further investigated. The main contributions are as follows.

  (1) A unified modeling framework for trusted collaborative computation offloading in space-based networks is constructed. Considering node heterogeneity, time-varying links, random task arrivals, and insufficient trustworthiness of state sharing, a collaborative computation model is established, including satellite terminals, satellite edge nodes, the ground control center, and the blockchain-based trusted control plane. Node resources, task attributes, link transmission, computation delay, energy consumption, node reputation, and task lifecycle recording are modeled. The overall offloading problem is then decomposed into a system-layer collaborative resource allocation problem and a task-layer concurrency-aware offloading problem, providing a unified notation system, state interface, and optimization objective for subsequent method design.

  (2) A blockchain and multi-agent reinforcement learning based system-layer collaborative resource allocation method is proposed. To address load imbalance caused by selfish node behavior, incomplete information, and resource competition in decentralized space environments, the system-layer resource allocation problem is modeled as a multi-agent Markov game. A blockchain-enhanced centralized training and decentralized execution framework is constructed. The consortium blockchain maintains public summaries such as node load, link status, reputation scores, and historical behaviors. A hybrid reward mechanism incorporating task completion quality, system fairness, and reputation incentives is designed to guide heterogeneous satellite nodes toward stable collaboration under autonomous execution. Experimental results show that the proposed method effectively improves task completion rate and load balancing performance. In a typical load scenario, the task completion rate reaches 92.3\%, and the Jain fairness index reaches 0.918.

  (3) A cluster-based federated learning and DQN based concurrency-aware task-layer computation offloading method is proposed. To characterize the hidden execution costs caused by CPU time slicing, cache conflicts, memory bandwidth contention, and I/O queue competition under multi-task concurrency, a task-level concurrency overhead model is established, where both the delay of the newly offloaded task and the increased remaining delay of existing tasks are incorporated. A closed-loop mechanism combining cluster-based federated learning based prediction and DQN based offloading decision-making is then designed. The proposed method trains concurrency overhead prediction models through clustered federated learning without uploading raw task logs, and feeds the predicted overhead, local state, and on-chain public summaries maintained by the blockchain ledger into a deep Q-network. As a result, satellite terminals can make forward-looking offloading decisions under delayed states and heterogeneous node data distributions. Experimental results show that, in high-concurrency scenarios, the proposed FL-DQN method achieves an average task delay of 256 ms and an SLA completion rate of 84.7\%, outperforming DQN-only, FL-only, and heuristic offloading strategies.

  In summary, this thesis forms a research system of “unified modeling--system-layer collaboration--task-layer offloading decision-making” for trusted collaborative computation offloading in highly dynamic space-based networks. The research provides theoretical foundations and methodological support for improving task processing efficiency, autonomous collaboration capability, and trusted operation in resource-constrained space-based networks.
\end{abstractEn}
