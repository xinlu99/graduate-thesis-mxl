\begin{abstract}
  随着天地一体化信息网络、低轨卫星星座和在轨智能处理技术的发展，天基网络正由传统数据传输网络向集通信、计算、存储与智能处理于一体的分布式协同计算网络演进。卫星终端试验任务数据具有来源分散、链路受限、时效性强和过程需可信记录等特点，传统星地集中处理模式易受可见窗口、回传带宽和传输时延限制，单星本地处理又受算力、能量、存储和星间链路条件约束，难以持续支撑高并发、高动态任务的快速闭环处理。因此，如何在异构、动态和去中心化的天基环境下实现可信状态共享、多节点协同资源分配、并发感知任务卸载与平台化运行支撑，已成为卫星终端试验任务数据管理与天基协同计算网络亟需解决的关键问题。

  针对上述挑战，本文围绕卫星终端试验任务数据管理与天基协同计算卸载需求，融合区块链、多智能体强化学习、联邦学习和深度强化学习等技术，研究面向天基网络的可信协同计算卸载方法。本文以区块链作为可信状态共享和任务数据存证底座，在系统层实现多节点协同资源分配，在任务层实现并发开销预测与实时卸载决策，并通过平台化架构支撑状态同步、模型治理、任务存证和执行反馈的闭环运行。本文主要研究内容如下：

  （1）提出基于区块链与多智能体强化学习的天基计算网络协同资源分配方法。针对去中心化天基环境中节点自利、信息不完全和资源竞争导致的负载失衡问题，本文将系统层资源分配建模为多智能体马尔可夫博弈，构建区块链增强的集中训练—分散执行协同决策框架。该方法利用联盟链维护节点负载、链路状态、信誉评分和历史行为等公共摘要，并设计融合任务完成质量、系统公平性与信誉激励的混合奖励机制，引导异构卫星节点在自治条件下实现稳定协同。结果表明，所提方法能够有效提升任务完成率和负载均衡水平，在典型负载场景下任务完成率达到 92.3\%，Jain 公平指数达到 0.918；在高负载条件下仍能保持较高任务完成率，并有效降低平均任务时延。

  （2）提出基于联邦学习与深度强化学习的并发感知任务层计算卸载方法。针对多任务并发条件下 CPU 时间片、缓存、内存带宽和 I/O 队列竞争引发的隐性执行代价，本文建立任务级并发开销模型，并构建“联邦学习预测 + DQN 卸载决策”的闭环机制。该方法在不上传原始任务日志的前提下，通过聚类式联邦学习训练并发开销预测模型，并将预测结果、本地状态和链上公共信息共同输入深度 Q 网络，使卫星终端能够在状态时滞和节点数据异构条件下完成具备并发风险前瞻能力的卸载决策。结果表明，在高并发场景下，所提 FL-DQN 方法的平均任务时延为 256 ms，SLA 完成率达到 84.7\%，优于 DQN-only、FL-only 和启发式卸载策略。

  （3）设计面向天基协同计算的区块链平台架构与运行机制。针对系统层协同优化和任务层实时决策缺乏统一承载环境的问题，本文构建面向动态星地网络的区块链协同计算平台。平台采用轻量级联盟链共识、分层链结构、链上/链下协同存储和智能合约治理机制，实现关键状态可信同步、试验任务数据存证、模型版本溯源、节点信誉演化和执行反馈回流。原型系统测试表明，该平台能够支持数据导入、上链存证、查询检索、完整性校验、历史追溯、权限控制和智能合约管理等功能，为协同计算卸载方法由算法验证向可信部署和持续演化转化提供了运行支撑。

  综上，本文面向卫星终端试验任务数据管理与天基协同计算卸载需求，构建了覆盖“可信共享—系统协同—任务决策—平台承载”的方法体系。相关研究可为资源受限条件下天基网络的任务处理效率、自治协同能力和可信运行水平提升提供理论依据与技术支撑，并为构建高效、智能、可信的天基边缘计算网络提供参考。
\end{abstract}


\begin{abstractEn}
  With the development of space-ground integrated information networks, low Earth orbit satellite constellations, and on-orbit intelligent processing technologies, space-based networks are evolving from traditional data transmission networks into distributed collaborative computing networks integrating communication, computation, storage, and intelligent processing. Satellite terminal test task data are characterized by distributed sources, constrained links, strict timeliness requirements, and the need for trustworthy process recording. Traditional space-ground centralized processing is limited by visibility windows, feeder link bandwidth, and transmission latency, while single-satellite local processing is constrained by onboard computing capability, energy, storage, and inter-satellite link conditions. Therefore, it is difficult to support fast closed-loop processing for highly concurrent and dynamic tasks. How to realize trusted state sharing, multi-node collaborative resource allocation, concurrency-aware task offloading, and platform-based operation in heterogeneous, dynamic, and decentralized space environments has become a key problem for satellite terminal test task data management and space-based collaborative computing networks.

  To address these challenges, this thesis focuses on satellite terminal test task data management and collaborative computation offloading in space-based networks. By integrating blockchain, multi-agent reinforcement learning, federated learning, and deep reinforcement learning, a trusted collaborative computation offloading method is studied. In the proposed framework, blockchain serves as the trusted foundation for state sharing and task data recording. At the system layer, it supports collaborative resource allocation among multiple nodes. At the task layer, it enables concurrency overhead prediction and real-time offloading decision-making. A platform-oriented architecture is further designed to support closed-loop operation, including state synchronization, model governance, task recording, and execution feedback. The main research contents are as follows.

  (1) A blockchain and multi-agent reinforcement learning based collaborative resource allocation method is proposed for space-based computing networks. To address load imbalance caused by selfish node behavior, incomplete information, and resource competition in decentralized space environments, the system-layer resource allocation problem is modeled as a multi-agent Markov game. A blockchain-enhanced centralized training and decentralized execution framework is constructed. The consortium blockchain maintains public summaries such as node load, link status, reputation scores, and historical behaviors. A hybrid reward mechanism incorporating task completion quality, system fairness, and reputation incentives is designed to guide heterogeneous satellite nodes toward stable collaboration under autonomous execution. Experimental results show that the proposed method effectively improves task completion rate and load balancing performance. In a typical load scenario, the task completion rate reaches 92.3\%, and the Jain fairness index reaches 0.918. Under high-load conditions, the method still maintains a high task completion rate and effectively reduces average task delay.

  (2) A federated learning and deep reinforcement learning based concurrency-aware task-layer computation offloading method is proposed. To characterize the hidden execution costs caused by CPU time slicing, cache conflicts, memory bandwidth contention, and I/O queue competition under multi-task concurrency, a task-level concurrency overhead model is established. A closed-loop mechanism combining federated learning based prediction and DQN based offloading decision-making is then designed. The proposed method trains concurrency overhead prediction models through clustered federated learning without uploading raw task logs, and feeds the predicted overhead, local state, and on-chain public information into a deep Q-network. As a result, satellite terminals can make forward-looking offloading decisions under delayed states and heterogeneous node data distributions. Experimental results show that, in high-concurrency scenarios, the proposed FL-DQN method achieves an average task delay of 256 ms and an SLA completion rate of 84.7\%, outperforming DQN-only, FL-only, and heuristic offloading strategies.

  (3) A blockchain platform architecture and operating mechanism for space-based collaborative computing are designed. To provide a unified execution environment for system-layer collaborative optimization and task-layer real-time decision-making, a blockchain-based collaborative computing platform is constructed for dynamic space-ground networks. Through lightweight consortium blockchain consensus, hierarchical chain structures, on-chain/off-chain cooperative storage, and smart contract based governance, the platform realizes trusted synchronization of key states, test task data recording, model version traceability, node reputation evolution, and execution feedback. Prototype testing shows that the platform supports data import, on-chain recording, query and retrieval, integrity verification, historical traceability, access control, and smart contract management, providing operational support for the transition from algorithm validation to trusted deployment and continuous evolution.

  In summary, this thesis constructs a complete framework covering trusted sharing, system collaboration, task decision-making, and platform support for satellite terminal test task data management and space-based collaborative computation offloading. The research provides theoretical foundations and technical support for improving task processing efficiency, autonomous collaboration capability, and trusted operation in resource-constrained space-based networks, and offers a reference for building efficient, intelligent, and trustworthy space-based edge computing networks.
\end{abstractEn}
